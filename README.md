# Ai RECORDS Radio Schedule

Alpha 0.1 of the Ai RECORDS radio broadcast dashboard, built with Next.js App Router and TypeScript for Vercel deployment.

## Features

- Ai RECORDS branded dark radio dashboard
- Live UK clock
- Now Playing and Next Up programme panels
- Today's JSON/TypeScript-driven broadcast schedule
- Schedule logic isolated from UI components
- Responsive layout and reusable component structure

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```
